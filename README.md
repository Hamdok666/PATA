# PATA – Pan-African Travel Agency

PATA is an innovative Pan-African online travel agency, connecting travelers with curated tours, accommodations, and experiences across Africa. The goal of PATA is to provide easy, seamless, and affordable travel solutions tailored for the African continent.

## Features
- Search for tours by destination, price, or duration.
- Book travel packages and experiences.
- Multi-language support (English, French, Arabic, Swahili).
- User authentication for travelers and operators.
- Simple booking management interface.
- Built with Next.js, deployed on Vercel.

## Technologies Used
- **Next.js 14**: React framework for building the UI.
- **Node.js**: JavaScript runtime environment for the backend.
- **AWS**: For deployment and cloud infrastructure.
- **Vercel**: Deployment platform for front-end and backend.
- **PostgreSQL**: Database for storing user and booking data.
- **TailwindCSS**: For responsive, utility-first CSS styling.
